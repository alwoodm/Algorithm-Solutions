# CSES

## About the Platform

The [CSES Problem Set](https://cses.fi/problemset/) is a collection of competitive programming problems maintained at the University of Helsinki. It is closely tied to Antti Laaksonen's *Competitive Programmer's Handbook* and covers the standard techniques section by section.

## Rules

All solutions are written from scratch, without a template.

## Structure

Each section has its own numbered folder, in the same order as on the website. Files are named after the problem, in lowercase with hyphens:

```
01-Introductory/weird-algorithm.cpp
02-Sorting-and-Searching/sum-of-two-values.cpp
```
